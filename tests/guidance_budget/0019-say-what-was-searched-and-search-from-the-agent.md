Two owner corrections land here and neither can be spent more cheaply. The
first is a truthfulness bound on the sentence the customer actually hears at
the gap: the inventory walks one project directory, so it may report what it
looked for and failed to locate, and may never report that no such material
exists. Real examples sit on shared mounts, behind paths configured in an IDE
instead of in `.env`, in sibling repositories, or under an environment variable
a fresh session never inherited. Denying them to somebody who has one open on
screen discredits every other line on that card, and the prohibition needs its
mechanism written beside it or the next editor will trade it back for a shorter
paragraph.

The second buys an ordering that the previous layout only implied. Stage 1 did
list the agent above the material, but nothing instructed the assistant to let
the agent DECIDE which examples and which grading method get selected. That
gap is invisible while a tree holds one candidate of each and expensive as soon
as it holds two, because the cheapest reading picks whichever file appears
first rather than whichever belongs to the agent under test. Naming the inputs
that do the deciding - what the agent does, the contract inferred a moment
earlier, the files its own call sites and tests reach - is what converts a
sequence into a method.

What is deliberately not bought is a restatement of the compatibility contract.
Whether the evaluator located this way genuinely grades the selected agent is
already settled in `references/component-creation.md`, so the flow cites that
home in one clause; searching from the agent turns that later check into a
confirmation instead of a coin toss. Nor is the dataset-versus-evaluator order
pinned, because no measurement here supports preferring either.

Both figures were taken with `assistant_facing_documents()` on this branch as
it sits on #209's head, the same tree entry 0018 was measured on. The resident
share is the flow edit alone; the larger half of the total is the reference,
which loads for one stage and leaves.
