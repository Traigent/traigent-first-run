Five rules governed the bounded subset and none of them said the drawn rows
have to be different. On a file holding three hundred rows that resolve to six
questions, or forty whole-row copies among a few hundred originals, a compliant
draw could put the same question in the eighteen several times over. The run
plan records eighteen ids, the money approval prices eighteen, and twelve
trials buy two hundred and sixteen provider calls to observe far fewer outcomes
than that. Nothing in the package objected, because every existing rule was
about where the rows come from - which split, which band, recorded how - and
none was about whether any two of them are the same row.

What these bytes buy is the missing property, and most of them go on saying
which readings of it are wrong. Sameness is keyed on the input alone, because
the agent writes one output per input: two rows carrying that input are scored
as a fixed pair by every configuration whatever answers sit beside them, so a
split of sixty questions under two accepted golds holds sixty examples and not
a hundred and twenty. Keying it on the pair would have priced the hundred and
twenty, and would have disagreed with the identity preflight already buckets
on.

Scope is the second half, and it was ambiguous in a way that costs calls. Read
inside one band, four repeats of another band's question still reach the
eighteen; read over the whole draw they cannot, and a band left with nothing to
add is a band the data tagged two ways - a finding to report rather than an
impossibility to assert. The floor of four and the new property meet there, so
the resolution is written down: a short band shortens the draw, and nothing is
borrowed from the bands that can fill.

The number the rule stops at is taken over the rows a run can score, which is
not the population a split holds. A file half collected and half annotated
publishes a larger count of different inputs than its comparison will ever
reach, and a paid draw sized from the larger figure keeps precisely what this
rule was written to remove. So the sixth rule names that population rather than
a metric key, and it names the boundary at the other end too: the held-out ten
is exact in both directions under its own heading, and nothing here reaches it.

The resident line moves because stage 6 named eighteen and priced "that
subset", which read as one number only while the two were always equal. They
can now differ downward, so the flow says the estimate is built from the rows
actually drawn and that the draw can come in under the default. A pricing
sentence naming a figure the run may not buy is the quiet disagreement between
two documents this package has already had four of.
