An external team instrumented a four-setting agent, proved every one of its settings alters the
outgoing request, and then watched the opening score follow one of them to the call. Recovering the
other three cost them two days, and every hour of it went on a rule nobody had written down: the
table a setting indexes may be read only in four shapes, so a debug string wrapping it in `tuple`
disqualifies it wherever in the module that string sits; a callable whose mapping is logged or
handed onward has only its first read of that mapping followed, so later settings lose on position
alone while an agent that keeps the mapping clean loses nothing at all; and a range has no
options to index at all, which left an interval-valued setting earning credit only if its author
built a mapping whose keys and values were the same numbers. Each limit is defensible and each was
invisible, and the third was actively teaching a bad habit inside a guide about good ones. These
bytes move all three to the stage where the citation is authored, beside the worked agent whose
settings do get followed, the entry that cites it, and the conditions applied to reach that verdict.
The worked halves are rendered from the constants the checker itself applies and a guard in the
package suite reds if either drifts, so this cannot become a second description competing with the
first; the hedge that it is one accepted shape rather than the only one travels with them, because
the harm the card is careful about is an author rewriting an agent a different route already covers.
The reason it belongs in the reference and not the resident flow is that only somebody already
writing the knob half needs it, which is one stage of one gate, and the resident figure is untouched.
Nothing is reworded or replaced; the paragraph stating the narrow form more loosely keeps its place
directly below, and the new text points at it as the other route rather than overriding it.
