# 0081 - the cited line is printed beside the sentence

An earlier raise bought the paragraph separating what a syntax tree can
contradict from what nothing decides, and it left one promise the reader had no
way to act on. Explanatory text beside each answer is authored by an assistant
and copied onto a customer's page unchanged. It can describe a wholly different
program: name a file the chosen agent is not, quote positions that file has and
this one lacks, and sit next to a structured citation that resolves perfectly
against the real thing. Somebody reading that page had nothing to weigh the
description against.

The bytes here buy the correction and, more importantly, they buy the argument
for why the correction is not a rule about wording. Refusing a description that
mentions some other filename sounds obvious until you write down what ordinary
projects look like. Instruction text lives in one module, tool declarations in
a second, response shapes in a third, and an author describing any of those
correctly names the module holding it. There is no property separating that
author from one who copied yesterday's reading of a neighbouring program,
because the neighbouring program is a file in the very same folder. Every
version of such a rule refuses truthful descriptions written by careful people,
and refusing truth to catch a copy is a bad trade at any ratio.

What replaces it costs nothing and cannot be worked around, because it asks
nobody anything. Positions in the structured citation are already confirmed to
sit inside the chosen agent and to name runnable statements. So the page now
quotes what those positions actually hold, taken out of the parsed file, next
to whatever the author wrote. A description of somebody else's program stands
next to this program's own text, and the disagreement is visible to the person
who most needs to see it. Nothing was deleted to make room: the sentence
explaining what somebody found is still there, because a position on its own
never said what was found.

A quotation is not a confirmation and the wording avoids ever suggesting one.
It reports where a reading claims to come from, in characters only the
customer's own file could supply. Two further paragraphs pay for boundaries the
addition creates rather than the addition itself: how much of a long generated
line appears before it is cut, and why an answer that settled nothing quotes
nothing at all. That silence is deliberate signalling. A reading admitting it
could not decide carries no position by construction, so there is nothing to
show, and showing nothing is exactly right.
