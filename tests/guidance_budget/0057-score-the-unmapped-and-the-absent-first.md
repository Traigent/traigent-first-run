The opening gate previously placed two correct instructions beside one another
without a deciding order. One told the assistant to map a custom schema, and
the other made a zero-row default read a distinct customer-visible result.
Workers consistently chose the mapping first, so the card never exposed that
the supplied file had not matched its default fields. They also treated a
recorded request/response log as the dataset itself, converting useful traffic
into a malformed dataset and changing the next action from obtaining rows to
reading fields that did not exist.

This short contract names the shared boundary. Inventory may find both kinds of
evidence, but the opening score first reports what its default dataset read
actually matched; only a later re-score may apply the discovered mapping. A
log remains source material, so an otherwise dataset-free project reaches the
honest absent-dataset route and can offer rows derived from its own traffic.
The additional sentence prevents a second provenance mistake: a prior model
reply is a generated candidate, not a reviewed expected answer. These bytes
replace an inference an assistant repeatedly made with an ordered, test-pinned
operation at the precise call site.
