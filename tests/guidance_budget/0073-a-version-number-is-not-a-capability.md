Two refusals paid for these bytes, and removing one of them is what funds most
of the text. The install step offered two routes into the dedicated
environment - the project's own "compatible exact declarations" or the tested
pins - and never defined compatible anywhere in this package. A project
pinning some other release read as the first route, so the run installed that
release and then met a check demanding the tested one, which turned an
ambiguity in our own sentence into a stopped walkthrough. Naming one route
costs fewer words than describing two, and the replacement says what the
separate environment is actually for: the customer's pin is theirs, this one
is ours, and neither has to move for the other.

The rest buys a finding the package could not previously state. Somebody who
already put the SDK in their project may be about to pay again for a guided
tour of something they own, and that is worth one sentence at the opening and
one line on the approval that already stops. It is deliberately not a gate.
The evidence available here - a dependency the customer declared - cannot
separate "installed it last week and never ran it" from "already tuned this",
and neither can an interpreter probe, which answers for one interpreter rather
than for the project. Refusing on either would turn away a second project, an
evaluation, or anyone who read the docs before running anything. So the words
have to carry what a stop would have carried: what was found, what it probably
means, and that the baseline and the search are still charged for. Two
placements rather than one, because the readiness turn is where findings are
read and the approval is the last moment stopping is free, and a fact that
only appears in the first has stopped being useful by the time it costs money.

One older sentence had to move with it. The deferred pre-install pass still
said an installed unsupported SDK was a failure, which was true only while any
other release counted as unsupported; leaving it would have left the package
disagreeing with itself about the same check, in the same document, which is
the contradiction these ceilings exist to price.

Trimming could not pay for this. The resident pair stood 61 bytes under its
ceiling before the edit, so any sentence added to the flow at all exceeded it,
and both places this guidance has to sit are resident by construction: an
instruction about the opening turn cannot live in a reference the opening turn
has not loaded, and one about the spend approval cannot either. Two passes of
trimming were done anyway and are in the figures: the opening sentence lost a
clause about why a guided run on an adopted project is ordinary, and the flow
gave its half of the install rule back to the safety reference rather than
saying it twice. Resident rises 901 bytes and the whole package 1_123, the
difference being the rule and its reasoning landing where that reference
already owns the environment.
