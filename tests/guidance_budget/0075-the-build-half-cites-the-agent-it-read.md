A blinded fixture re-run spent these bytes before anyone wrote them down. Its
dataset was rebuilt underneath it, so the recorded invariants no longer matched
and the run correctly refused to resume: it retired its record, copied a fresh
template, and restarted at stage one for a new opening score. What it carried
across that boundary was the previous run's reading of the agent, byte for byte,
sha256 unchanged. Half of that document was refused on arrival by the coordinate
check every parameter already had to pass. The other half was printed onto the
customer's card as an observation about their program.

Nothing was lying. The reading happened; it just happened to a snapshot, and the
artifact carries no mark saying when. That absence is deliberate elsewhere in
this package - a settings file left by an older run is named as context and
barred from scoring, twice, in two separate documents - and the reading of how an
agent is put together had no such bar anywhere. So the two rules that govern it
point opposite ways and neither one is wrong: pass the same reading to each
later score within a run, and treat a reading as evidence about source at the
moment it was taken rather than something to hand forward. A restart inside one
session is both, and the paragraph that describes restarting settles neither.

The bytes go to the reference that owns this document's shape, beside the
paragraph that already explains why a parameter must name physical lines. Each
settled check now names them on identical terms, and the explanation says what
the naming is for: prose sitting next to a claim is explanation, and the scorer
has never parsed it for a coordinate, on purpose - a permissive reader of
`path:line` suffixes accepts malformed ones. Without a structured list, then,
this was the single assertion about somebody's code that reached a score with
nothing standing behind it.

An unsettled check names no line, and that asymmetry is the point rather than an
exemption. A read that could not resolve the question has nothing to point at,
and charging it for a coordinate would make the truthful answer more expensive
to give than the confident one, which is the failure this whole gate is built to
avoid.

What the customer gets for the spend is that a stale reading now announces
itself. Lines drawn from a file that has since been edited, or from some other
program entirely, fall outside the selected source and are refused with the
remedy attached, in place of a card that reported one agent while describing
another. In the run that prompted this, the printed claim was that the program
takes one turn and stops. The program it was scored against loops forever.
