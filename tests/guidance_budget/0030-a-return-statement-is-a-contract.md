# 0030 - a return statement is a contract

follows: 0029
total-ceiling: 349_200
total-measured: 348_739

The build half asked whether an answer's shape is pinned down and then listed
four ways to pin it, every one of them a declaration standing outside the
function: a parser, a schema, a response format, an instruction naming a format.
The commonest way a shape is actually fixed was absent from that list, and the
single worked example beside it showed a parser, so both signals pointed away
from the source itself. A reader following the text arrived at "not pinned" for
a function whose literal return statement leaves an evaluator nothing to
discover.

This was measured rather than supposed. A blinded run of the broken-evaluator
case recorded the check as absent and landed one point below the recorded
derivation, and the disagreement turned out to sit entirely in this clause. The
cheapest response would have been to hand the next worker the missing sentence
in its briefing, which converts a defect in the guidance into a permanently
green result: every later run inherits the coaching, the text stays wrong, and
nothing ever surfaces it again. The sentence belongs where a customer's
assistant will read it unprompted.

What the bytes buy is therefore the missing form plus the distinction it depends
on. Fixing a shape and performing a task are different properties of the same
nine lines, and an echo that returns a dictionary satisfies the first while
failing the second. Saying so explicitly closes the reading where a stub is
denied a check it earns merely because it is a stub. The clause naming that
separation is doing more work than the enumeration it follows, because the
enumeration can be extended by anyone and the confusion behind the omission
cannot.

Both homes move together. The flow does not state this rule at all, so the
raise is spent on the reference that owns the stage and on the glossary line a
reader consults while explaining the check, which had drifted into the same
four-item list. Leaving one of them widened would put two answers to one
question in a repository whose history is four contradictions of exactly that
shape.
