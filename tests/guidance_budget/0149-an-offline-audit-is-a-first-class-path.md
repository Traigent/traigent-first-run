A customer who asks for an offline audit reached no defined path: the guide never said to stay
disconnected, never said where to stop, and never named the report. A field test on 2026-10-01
had the assistant assemble all three by itself, and preflight called an inherited Traigent key one
"to be sent" during a run that sends nothing. SKILL.md gains a short "Offline audit" section, 979
bytes of resident guidance with GUIDE.md's one-line pointer: unset the inherited variables for
every command, pass the new preflight flag, stop at the Stage 4 approval, save the report under
four fixed headings, and a reading plan that skips the references this path never needs. That plan
is what pays the bytes back at run time, since an audit run no longer opens two of the five
references. run-safety.md grows 377 bytes, which is also the largest document, to say that the new
find_python.py script runs the interpreter search that paragraph already described and returns a
path with symlinks resolved, because an environment made through a symlinked interpreter is
refused by the installer. The figures above are the measured tree.
