Two runs of the same project announced different stages. The guided flow is
numbered one to eight and the customer is shown five, and nothing said which
numbering reaches them, so one assistant printed its section number against the
five denominator and told the user "Stage 5/5 setup is complete" while baseline,
comparison and results were all still ahead. That reads as a run about to end,
immediately before the first approval that spends money. These bytes name the
displayed stages as the only ones an assistant may announce and mark the section
numbers as internal, which is cheaper than teaching each reader the mapping.
