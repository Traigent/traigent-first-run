# 0029 - stub agents are not opening evidence

follows: 0028
resident-ceiling: 76_900
resident-measured: 76_779

The taskfulness rule belongs at the opening gate because it decides whether an
agent source is evidence or a placeholder before readiness receives
`--agent-knobs`. Moving it to a later reference would leave the source read
unconditional at the only decision point and could again award credit to an
echo. This measurement includes the aligned contract test and behavior lock.
The 121-byte headroom is deliberately narrow: the next resident mandate must
be weighed rather than absorbed as an unexamined wording change.
