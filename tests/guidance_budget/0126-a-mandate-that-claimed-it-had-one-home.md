Seventy bytes, no resident movement, and most of the value of this entry is in what it does NOT
change. A sweep proposed four one-decision-one-home repairs to this file and two of them were wrong
about the tree, which is the thing worth writing down: both were refused by guards this package
already runs, and finding that out cost less than shipping either would have.

What lands is the route-marking rule. It is stated in full in the component reference and again in
outline here, and the sentence introducing this file's copy asserted the opposite - that the rule is
stated there once and is not restated here - three lines above a paragraph conceding where its home
is. A claim of single-statement printed beside a second statement is worse than the duplication it
describes, because it tells the next reader not to go looking. It now names the owner and says
plainly that this file does not repeat it.

And a cross-reference whose range stopped one section short. This file's own post-run verification
block is ordered by section 8 and cites section 8 by name elsewhere, while the ordering pointer
offered four through seven.

Refused, first: consolidating the walkthrough ceiling's default into one home. The figure is stated
in five documents deliberately. A shared-value table holds them equal, and a second check asserts
that the table's pattern actually REACHES each document - its own comment records the ceiling
pattern once failing to match a bare `$5`, so the one shape the value had drifted into was the shape
nothing could see. Removing the figure from the flow document did not tidy a duplication; it took a
document out of the coverage the guard measures. Restatement plus a machine-checked equality is the
mechanism here, and it is stronger than one home with no check at all.

Refused, second, and this one nearly shipped: rewriting the key-creation message because a read-only
key is supposedly not refused. Two different paths were being conflated. A manually created
read-only key IS refused, at session create, by the pinned SDK, before any trial runs - and a test
docstring in this package already separates that from the later 403 that degrades a running
optimization to local-only. That docstring also records an earlier revision of itself asserting the
false version, which is how a sentence about a live system goes stale twice. The message was right
and stays.
