The scorer gained two conditions, and each one had to gain a bullet, because an
assistant meeting a condition id with nothing beside it has no next step to take
and no words to give the person reading the card. The suite refuses that gap
directly: every condition the module can emit is checked against the routing
lists, so a ceiling nobody wrote a branch for cannot ship.

The first bullet names an agent that never reached the score at all. Three
pillars are graded here and only two of them could report their own absence, so
a project holding no agent whatsoever met a ceiling about search spaces and was
told to give one of its settings a second value - a change to a file it does not
have. The branch sends that run to connect or create the thing being optimized,
which is what the other two components already ask for when they are missing.

The second names rows repeating another row's question. Those were bounded only
while their identifiers happened to collide, under a printed sentence about
lines nobody could read, and renumbering thirty of them cleared a ninety-row
file outright. So the branch carries the two answers that belong to the
customer - stay with the questions that differ, or replace the copies in their
own file - and it deliberately stops short of offering to write anything, since
the run may not substitute material nobody asked it for.

A handful of the bytes narrow an existing promise rather than adding one. The
search-space ceiling stays advisory for a run that named the agent it could not
open, and the sentence extending that reading to every evidence-free card
stopped being true the moment absence became a condition of its own.

Both figures above are the merge, not this branch alone. Measured against the
entry it now follows, the two bullets and that narrowing take 349 of the 465
bytes its resident raise had left and 483 of its 497, which would have left the
next author fourteen bytes and no warning that they were the last ones. Neither
branch could have arithmetic the other had not done yet, so the numbers are
restated here against the tree that actually exists and the room is put back.
