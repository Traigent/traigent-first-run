Two independent blinded first-run attempts against the same project read a pre-existing evaluator, watched it pass calibration, and declared it `brought` even after the customer had already said nothing sitting in the folder was something they wrote or vetted. Both attempts anchored the origin call on the file's own text and never revisited it once the customer had spoken to the question directly. The prior guidance named who decides and said not to ask, but said nothing about weighing what a customer already volunteered against what the source shows, so a clean-reading substitute kept sliding into the customer's own category by default. A first version of this entry only said what the disclaimed file was not, and review of that version found the gap it left open: `generated` was defined as "one this run created," so a disclaimed file this run had not yet rewritten had no valid value to declare, `brought` refused and `generated` untrue. The second sentence closes that hole by widening what `generated` names to anything this run relies on standing in for material the customer did not bring, whether typed fresh or adopted as found. Nothing existing is reworded, only added to.
