Entry 0022 bought the instruction to open the agent and write down what it can
already vary, and closed with one conditional clause: skip that work when there
is nothing to open. Read literally, "nothing to open" swallows an agent written
in another language, an agent compiled before this run saw it, and an agent that
lives behind a network call - none of which is an absent agent. A customer in
any of those positions was handed the unestablished-space ceiling as a verdict,
with a reason describing what nobody had supplied and no move they could make.

The correction needs prose because the module underneath it cannot help. Its
`AgentFacts` records whether a document or a reading arrived and holds no fact
about whether an agent exists, so a project with none and a project whose agent
resisted inspection are one state by the time anything is scored. Splitting them
in arithmetic would mean a new input, a new branch and a re-proof of the
ordering property; stating plainly at the gate that the reading is unconditional
wherever an agent turned up costs a few lines and removes the state instead.

The rest of the addition is the routing, and its length is the argument. Reach
and evidence are different things: failing to open somebody's file says nothing
whatever about their project, so the honest response names it, says what stopped
the reading, invites a pointer to source that can be read, rides on whatever
question the turn already carries rather than adding another, and continues
regardless when nothing arrives. One clause of that is a prohibition and earns
its bytes twice over: asking for a settings file would contradict the sentence
directly above, which throws away every such file predating this search, so the
customer would answer a question whose answer must then be discarded.

The ceiling is kept and its interpretation is not repeated. Stage 4 already
rules on what an advisory reading of it means, and a draft of this entry both
restated that ruling and shrank it to callers with nobody present - untrue,
because a closing card following a halted or empty search lands on the identical
advisory reading while the customer watches. Pointing costs a clause; owning it
twice costs a disagreement nobody would notice.

The figures above were restated after review, and three corrections moved them.
The invitation now names where it rides and tells the caller to withhold the
flag while no reading finished, since handing the scorer an empty one converts a
question about our reach into a published verdict about somebody's agent. Every
later scoring call in the walkthrough inherits the same reading, because a gate
that drops it silently prints a fall the customer is invited to believe happened
inside their own project. And the one call that keeps withholding it says why in
the safety reference: the closing number weighs what a search was handed, so
letting source stand in for a document nothing produced would raise exactly the
ceiling protecting a run that bought no trial.

74_154 and 325_095, taken with `assistant_facing_documents()` on the integration
merge, not on the branch that declared 67_481 and 307_548. They repeat the two
numbers on 0022 rather than differing from them, and the repetition is the
honest reading: both entries land in one merge, so there is one package and one
measurement of it, and inventing a difference between them would mean quoting a
tree nobody built. This entry is the last along the chain, so these are the
ceilings in force - 74_400 and 325_400, both above what was measured here.

Two things were verified on the merged tree before either figure was written,
because they are the reason this pair had to land together. An agent found and
not readable leaves `--agent-knobs` off, and the card that follows carries the
advisory cap, `status: OK`, and no sentence claiming a read: executed, it prints
"No settings document and no reading of the agent reached this score". Handing
the scorer the empty document instead prints "The agent was read and no setting
it can vary was found" and blocks - which is the published verdict about
somebody's agent that the clause above exists to prevent. And the question that
receives the deferral accepts it: #211's trigger fires on material the inventory
"found and could not read out of", so the offer this gate makes arrives
somewhere instead of nowhere.
