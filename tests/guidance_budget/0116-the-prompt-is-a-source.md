Thirteen hundred bytes, no RESIDENT, and they name a place the matrix was already sending readers
past. Two rows direct a run to build a dataset around a real agent, out of its inputs and its
failure modes, and neither names the one file that most often already holds real question-and-answer
pairs: the worked examples inside the agent's own prompt. Their author believed each one was
correct, wrote it in the product's vocabulary, about the product's task. A run that invents rows
beside that file has invented weaker evidence than the file it did not use.

It is close to free where it applies, which is the argument for spending anything. The prompt is
already open - the build checks read it - and the coldest start this guide handles is exactly the
row where a generated corpus is likeliest and most heavily ceilinged. Material the customer wrote
lifts what the comparison rests on without lifting a ceiling it has not earned.

Two bounds travel with it and both narrow rather than widen. Examples embedded in prose carry no
syntactic marker, so finding them is a reading and never a parse, and a row taken from one is
recorded by id exactly like any other row this run writes. And the harder half is refused here
rather than half-answered: whether a prompt's examples AGREE with a dataset that already exists is a
separate finding about two artefacts written at different times, and a paragraph that gestured at it
without saying who checks it, against what, and what a disagreement costs would be worse than
leaving it named and open.
