# 0061 - informed key handoff

follows: 0060
follows-total-measured: 429_933
total-ceiling: 430_500
total-measured: 430_436

The paid Enhanced handoff must show the current pricing, terms, and privacy
sources before it asks for a Traigent key, while stating plainly that those
sources do not establish whether submitted material is used for training. That
is a required informed stop, not optional account-help prose. Restoring the
tested registration sequence beside it preserves the customer’s actual route
to the key instead of shortening the flow until only test phrases remain. The
increase records both facts transparently; it does not claim the unavailable
training-use policy has been resolved or authorize a key handoff without it.
