Two hundred and twenty bytes of RESIDENT, and they are not prose: they are the dispatch line that
makes the rest of this reachable. Sections of a reference are opened by the dispatch that names
them, and one that no stage points at stays closed - so a route written without a pointer is a route
nobody takes, and the cost of the pointer is the cost of the rule existing at all. The rest sits in
the safety reference beside the stop it is not.

What it buys is consent arriving before the thing consented to. A scorer that replays a workflow
reaches no engine: it calls the project's own functions, so the containment walk is silent, and four
probes drive that workflow four times before anyone has been asked. The customer's first chance to
object lands after the effects.

The trigger is what the effect DOES, and the two alternatives are refused in the text rather than in
a review nobody will find later. Widening the walk to any project call cannot work - no static
signal tells a function that appends a line from one that despatches a message - and refusing on the
existence of any effect fires on read-only retrieval, which is the false-refusal shape that made the
wide walk unacceptable in the first place. Where the workflow changes nothing, there is nothing to
consent to.

The clause that earns its own sentence is that the ask names the actual functions, database calls
and tools the replay reaches. Approving a category is not approving an action, and this run has
already read the path it would be describing, so there is no reason to put a vague question when a
concrete one costs the same.
