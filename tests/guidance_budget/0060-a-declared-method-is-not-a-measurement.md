Opening readiness can safely read a declared evaluator method, but cannot
import arbitrary customer code merely to prove the scorer uses its inputs. The
new route names that boundary instead of silently treating metadata as a
measurement: the opening card stays bounded, and the existing approved
calibration supplies the first behavioral evidence. This earns a small
resident increase because the route must sit beside the other evaluator caps
the assistant reads before choosing whether to repair, create, or continue.
