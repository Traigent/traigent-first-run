A confirmation for a single discovered agent had been written as a halt of its
own. That is one halt too many. The question this package already asks when
material is absent accepts an `agent:` reply, so putting the discovered path
inside that question buys exactly the same correction for no extra interruption,
and a project where nothing is absent still hears the path named at the approval
which precedes any charge. Removing a stop is worth spending bytes on precisely
because the stop itself was cheap to add and expensive to sit through.

Most of what is bought here replaces the sentence that halt used to carry, and it
lands in the reference rather than the flow. Somebody whose only anchor is a
callable named for arithmetic should hear arithmetic back; somebody whose tree
holds recorded traffic should hear that rows will be built from that traffic
rather than invented. Neither sentence is derivable from a generic apology about
examples nobody located, and a customer cannot weigh an offer whose subject is
left blank. Recorded request and response traffic joins the discovery list for
the same reason: a tree with no examples very often owns everything needed to
make some, and a search which never looks there reports an absence it did not
test.

The closing clause pays for honesty about degree. One fabricated piece standing
beside genuine rows, a genuine ruler and a genuine callable is a weaker claim
than three pieces spun out of a single line of stated intent, and the scorer has
separated those two since it was written. Reusing one sentence for both flattered
the first and libelled the second.

76_711 and 347_996, measured on this branch with `assistant_facing_documents()`
after the flow edit, the discovery line and the reference section were all in
place. Both figures sit under the ceilings they buy with room for a correction,
and neither budget is lowered here.
